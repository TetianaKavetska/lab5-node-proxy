# Лабораторна робота №5

## Тема
HTTP-сервер на Node.js із кешуванням зображень.

## Мета
Навчитися створювати HTTP-сервер на Node.js,
працювати з HTTP-методами та кешуванням,
тестувати API за допомогою Postman.

## Використані технології
- Node.js
- JavaScript
- Commander
- Superagent
- Git
- Postman

## Реалізовані можливості
- GET — отримання зображення
- PUT — завантаження зображення
- DELETE — видалення зображення
- Кешування зображень
- Обробка помилок HTTP
- Автоматичне тестування API

## Запуск сервера

npm install

node main.js --host 127.0.0.1 --port 3000 --cache cache

## Тестування

Для перевірки API створено колекцію
Lab5 Caching Proxy у Postman.

Колекція містить 8 HTTP-запитів.

Перевіряються:
- HTTP-статуси 200, 201, 404, 405
- Заголовок Content-Type
- Заголовок X-Cache
- Завантаження та видалення зображень

## Висновок

Під час виконання лабораторної роботи було
створено HTTP-сервер на Node.js із підтримкою
кешування зображень.

Було реалізовано методи GET, PUT та DELETE,
перевірено обробку HTTP-запитів і протестовано
роботу сервера за допомогою Postman.
